# Phase 5 离线验收矩阵

本矩阵把多子任务与项目记忆的关键边界映射到可执行测试。测试使用脚本化模型；Git worktree 用临时真实仓库创建。它们不代表真实模型服务、跨设备或公开发行验收。

| 场景               | 必须成立的结果                                                                                                                               | 测试                                                                                                                                                                                                                       |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 父子来源           | 首个持久事件记录父 Thread，索引重建后仍可查询                                                                                                | `thread-metadata-index.test.ts`: `rebuilds parent-child lineage from the first durable turn`                                                                                                                               |
| 只读同步派遣       | 子任务独立运行，不能获得写入或执行工具，回答返回父任务                                                                                       | `application.test.ts`: `delegates a bounded read-only task to an independent child thread`                                                                                                                                 |
| 只读异步协调       | 启动后可发送下一步消息、等待有界结果                                                                                                         | `application.test.ts`: `spawns a read-only child, steers it, and waits for its result`                                                                                                                                     |
| 数量与取消         | 每个父 Turn 最多启动两个子任务；中断或父任务取消会结束运行中的子任务                                                                         | `application.test.ts`: `limits read-only delegation to two children per parent turn`, `interrupts a running asynchronous child and reports cancellation`, `cancels an active read-only child when its parent is cancelled` |
| 可写隔离与共享笔记 | 审批后从固定 HEAD 创建 worktree；子任务可修改该 worktree、读取源工作区的显式笔记，源工作区不变；子任务无命令与再次派遣工具；结果与血缘可查询 | `application.test.ts`: `runs an approved write child only inside a detached Git worktree`                                                                                                                                  |
| 审批拒绝           | 拒绝派遣时不创建 worktree、不修改源文件                                                                                                      | `application.test.ts`: `does not create a worktree when child delegation is rejected`                                                                                                                                      |
| 审批期间 Git 变化  | 源 HEAD 改变后，已批准的旧预览不再创建 worktree                                                                                              | `application.test.ts`: `refuses an approved worktree when source HEAD changes during approval`                                                                                                                             |
| 消息边界           | 消息在下一模型步前持久化；容量受限，末步开始后拒绝                                                                                           | `agent-loop.test.ts`: `bounds and closes its in-memory steering mailbox`, `records queued steering before the next model request`, `rejects steering during the last allowed model step`                                   |
| 工作区授权         | 远程接口只向正确的 Thread/Turn 排队消息                                                                                                      | `app-server.test.ts`: `queues steering for the next model step and rejects a different thread`                                                                                                                             |
| 项目笔记           | 笔记按工作区持久化、可编辑，旧版本写入被拒绝；不安全目录被拒绝                                                                               | `project-note-store.test.ts`: `persists editable workspace-scoped notes and rejects stale writes`, `keeps corrupted notes and rejects an unsafe note directory`                                                            |
| 检索               | 固定离线查询集测量 Recall@3 与 MRR，模型只获得有界读取工具                                                                                   | `project-note-store.test.ts`: `measures exact lexical retrieval on a fixed project-note fixture`; `project-note-application.test.ts`                                                                                       |

运行：`pnpm -r --if-present build && pnpm exec tsc -p tsconfig.test.json --noEmit && pnpm exec vitest run`。上述检索指标只适用于测试夹具，不能外推到真实项目查询。
